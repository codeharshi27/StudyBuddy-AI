# StudyBuddy AI

An AI chatbot tutor built for **UN SDG 4: Quality Education**.

## Problem
Many students, especially in rural and low-income areas, lack access to paid tuition and structured learning support.

## Solution
StudyBuddy AI is a custom AI tutor built with Google Gemini (Gems). It explains topics in simple language, quizzes students, creates study plans, and recommends free learning resources.

## Features
- Simple topic explanations with real-life examples
- Instant 3-question quizzes with feedback
- Personalized 3-step study plans
- Free resource recommendations (Khan Academy, NPTEL, SWAYAM, YouTube)

## Technology
- Google Gemini (Custom Gem)
- Prompt engineering / natural language instructions (no-code)

## Files
- `instructions.md`: the full instructions given to the AI
- `screenshots/`: proof of the working chatbot
